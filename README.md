# Reyhane Alizadeh — Personal Portfolio

A modern personal portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## 🌐 About the Project

This is my personal developer portfolio website, designed to introduce my background, skills, projects, education, and development journey.

The website focuses on a modern dark interface, responsive design, clean component architecture, and a professional developer-oriented presentation.

## ✨ Features

- Modern dark UI
- Fully responsive design
- Hero section
- About section
- Skills section
- Projects section
- Development journey
- Education section
- Contact section

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/reyhanealizadeh06/personal-website.git
```

Go to the project directory:

```bash
cd personal-website
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
